A focused chatbot for commercial support

Instead of inventing answers, Nova ranks known support patterns and uses a safe fallback when confidence is low.

⌁

Retrieval matching

TF-IDF, cosine similarity, keyword signals, and typo-tolerant character similarity select the best known response.

✓

Predictable replies

◈

Privacy by design

Messages stay in the browser. Conversation history is saved locally and can be cleared at any time.

How it works

Four steps from question to answer

  1. 1

    Normalize

    Clean and expand user text with common commercial-support synonyms.

  2. 2

    Vectorize

    Build term-frequency vectors with inverse-document-frequency weighting.

  3. 3

    Rank

    Combine cosine, keyword, and typo-tolerant similarity signals.

  4. 4

    Respond

    Return the matched response or a safe fallback below the confidence threshold.
